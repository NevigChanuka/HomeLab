# Review changes

1. Read the complete diff and related files; check scope and placeholder status.
2. Look for correctness, secrets, unsafe defaults, deployment side effects and missing rollback.
3. Verify validation covers implemented behavior and does not silently skip failures.
4. Confirm documentation and examples match the change.
5. Report actionable findings with file locations, impact and suggested fixes.
   State what was tested and what could not be verified. Do not invent findings.
